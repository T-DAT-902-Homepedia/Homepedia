# Intoduction

Ceci est la documentation du project Homepedia (T-DAT-902), c'est un projet de développement Big-Data qui a lieu dans le cadre du 10eme semestre d'études à Epitech pour les étudiants en MSc Pro.

Cette documentation est supprosée présenter notre processus de conception et développement et l'application résultante.

Les différentes briques logicielles du projet devraient être documentées dans les différentes sections.

> [!NOTE]
> Ce site web à été construit avec `mbBook` vous pouvez [consulter sa documentation](https://rust-lang.github.io/mdBook/guide/creating.html) pour comprendre comment créer de nouvelles pages.

Suite à la découverte de principe d'ADR (Architectural Decision Record), il à été décidé par [@glopez-dev](https://github.com/glopez-dev) et [@ndaen](https://github.com/ndaen) que la suite de la documentation pourrait être structurée sous forme d'ADRs organisées en catégories suivant les briques logicielles impactées. 

*La décision d'utiliser des ADRs est donc la première ADR :)*

> [!WARNING]
> En début de projet, vous devez tracer au moins 1 décision par semaine, dans la suite peut-être une par sprint. Si vous en tracez moins, vous êtes probablement en train de prendre des décisions non conscientes : une partie de l’équipe n’est sans doute pas au courant des décisions et vous ne mesurez pas l’impact de celles-ci.
