# Intoduction

Ceci est la documentation du project Homepedia (T-DAT-902), c'est un projet de développement Big-Data qui a lieu dans le cadre du 10eme semestre d'études à Epitech pour les étudiants en MSc Pro.

Cette documentation est supprosée présenter notre processus de conception et développement et l'application résultante.

Les différentes briques logicielles du projet devraient être documentées dans les différentes sections.

> Ce site web à été construit avec `mbBook` vous pouvez [consulter sa documentation](https://rust-lang.github.io/mdBook/guide/creating.html) pour comprendre comment créer de nouvelles pages.
